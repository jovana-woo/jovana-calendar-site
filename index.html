Jovana Calendar (조바나 캘린더)

Jovana Calendar는 Windows 바탕화면에 월간 달력을 표시하고, 사용자의 Google Calendar와 일정을 양방향으로 동기화하는 개인용 데스크톱 앱입니다.

Jovana Calendar is a personal Windows desktop widget that shows a monthly calendar on the desktop and syncs events with the user's own Google Calendar.
